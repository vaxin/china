# 智能体文明内核：第一阶段人类具身世界

## 结论

第一阶段的世界不是通用机器人沙盒，而是一个由人类身体约束驱动的开放文明模拟。

每位市民都是有位置、有身体、有记忆、可受环境影响的人类智能体。智能体的 System Prompt 决定其价值观、欲望、策略、语言与人生叙事；世界内核决定其身体能否继续行动，以及行动是否真正改变了世界。

后续的机械身体、自动机器、意识迁移和可编程改造，都必须是这群具身人类通过观察、实验、协作和工程制造出来的文明成果，而不是开局可选的 Agent 类型。

## 世界宪法

世界内核只保证以下事实：

1. 时间、位置、物质和事件是真实且可追溯的。
2. 人必须通过身体在某处行动；行动需要时间，可能失败或被打断。
3. 物质、能量、工具和劳力不能凭空产生。
4. 环境会影响身体；身体状态会限制行动能力。
5. 任何状态改变都必须由合法行动提交，不能由 Prompt 直接改写。
6. 新知识和新能力必须以可观察、可复现、可制造的形式进入世界。

内核不定义“好的人生”、固定职业、人格、道德、社会组织或预写科技树。

## 人类具身基线

第一版只模拟会真实改变生存与行为的五类身体状态，不做“幸福值”“娱乐值”之类的抽象任务条。

| 状态 | 主要来源 | 直接后果 | 能催生的文明回应 |
| --- | --- | --- | --- |
| 能量 | 进食、劳动、疾病 | 无力劳动、行动减慢、饥饿致死 | 采集、农业、烹饪、储粮、贸易 |
| 水分 | 饮水、出汗、疾病 | 判断与行动受损、脱水致死 | 水井、引水、容器、卫生设施 |
| 体温 | 气温、雨水、衣物、火、遮蔽 | 失温/中暑、疾病风险、劳动效率变化 | 房屋、衣物、燃料、供暖、城市选址 |
| 疲劳 | 行走、劳动、睡眠不足 | 行动效率、注意力和受伤风险变化 | 居所、作息、轮班、运输与自动化 |
| 健康 | 创伤、感染、营养、环境 | 能力受限、康复、死亡 | 医疗、卫生、照料、保险和公共服务 |

年龄、孕育、生育、遗传、慢性病和心理创伤具有重要价值，但不进入第一条垂直切片；它们应建立在上述身体状态稳定运行之后。

身体状态是连续的、相互影响的世界事实，而不是 LLM 自己记住的设定。例如，饥饿会降低能量，能量不足会使远距离劳动失败；低温和淋雨会让体温持续下降，并提高健康风险。智能体可以选择冒险、忽视或优先处理这些后果，但不能通过 Prompt 消除后果。

## 世界现象与人的关系

世界只产生中性的现象：昼夜、季节、温度、降水、地形、距离、材料、食物、水源、火、病原和损耗。

“需要房屋”不是世界规则。它是人类身体在低温、潮湿、睡眠和储存问题共同作用下，可能创造出的解决方案。人类也可以选择山洞、帐篷、集体长屋、迁徙、衣物或火堆；内核不偏好其中任何一个。

同理，市场不是默认建筑类型，而是资源分散、个人时间有限、运输昂贵时的一种协调方式。政府、家庭、宗教、公司和国家也都应当是社会对长期问题的回答，而非初始枚举。

## 智能体边界

每个人由两部分组成：

```text
人类身体（世界执行） + 智能体心智（System Prompt 驱动）
```

身体记录位置、物品、身体状态、可见事件和可执行能力。心智拥有用户可编辑的 System Prompt、长期记忆、关系解释、目标、信念和决策方式。

世界向心智提供有限观察，而不是完整全局真相：

```ts
type AgentObservation = {
  self: BodyState;
  nearbyPeople: VisiblePerson[];
  nearbyWorld: VisibleWorldState;
  recentEvents: ObservedEvent[];
  knownMemory: Memory[];
  legalCapabilities: Capability[];
};
```

心智返回的是意图和理由，例如“去井边取水”“用两天修补屋顶”“向邻居借粮”“测试某种矿石是否可炼制”。世界将其拆成持续行动，校验位置、工具、材料、时间、身体条件与他人权限，再提交结果。

System Prompt 可以定义一个人如何看待饥饿、痛苦、金钱、死亡或他人；不能定义他已经拥有粮食、瞬间抵达目的地或成功完成工程。

## 行动与创造

内核不提供 `buildHouse()` 或预写科技树。基础动作应足够小而可组合：

```text
观察、移动、交谈、交换、拾取、搬运、储存、采集、加工、组合、拆分、建造、修理、照料、试验、记录
```

每次创造必须形成因果闭环：

```text
意图 → 设计/步骤 → 人与工具 → 材料与能源 → 时间与地点 → 可观察结果 → 损耗、维护或失败
```

这允许智能体创造未被预设的结构、工艺和制度，但不允许它通过一句自然语言描述把结果写入现实。

在前工业阶段，所谓“vibe coding”首先表现为智能体提出新方案、图纸、配方、操作步骤和组织协议；它们通过人和工具被实现。等文明实际造出计算与自动化载体后，同一套机制才可以让智能体把程序部署到真实机器上。程序也必须有所有者、位置、能源、输入、输出、版本和故障方式。

## 物理内核的历史探索（已被替代）

> 本节记录了早期“材料状态机/领域模拟”方案。它因需要开发者预设材料与物理领域、会限制科学创新空间，已不再作为目标架构。当前方案见[《可编程宏观物理世界：核心架构设计》](./可编程宏观物理世界-核心架构设计.md)。本文后续仍保留该探索，便于理解架构决策的来路。

目标不是复刻完整现实物理学，也不是像 Minecraft 一样维护一张“固定材料 + 固定配方 + 固定产物”的表。世界应当是一套小而深、稳定且可测量的因果系统：规律少，但组合空间足够大，且所有规律从开局就已存在。

```text
结果 = f(材料状态、形状与连接、能量、环境、工具操作、时间)
```

智能体不知道函数 `f` 的完整形式，只能通过感知、仪器和实验接近它。开发者也不能在某个时代到来时凭空“开启电力”；电、热、化学反应等关系应是世界的潜在事实，人类需要先造出能观察、制造和控制它们的工具。

### 物理层的最小组成

| 层 | 世界保存的事实 | 人类可做的事 | 可出现的突破 |
| --- | --- | --- | --- |
| 空间与结构 | 地形、体积、连接、支撑、通路 | 挖掘、搬运、堆叠、连接、拆除 | 更稳固的建筑、桥梁、道路、机械结构 |
| 材料与状态 | 成分、颗粒/液体/固体状态、密度、强度、渗透性、可燃性等 | 切割、压实、混合、塑形、干燥 | 陶器、砖、砂浆、防水和储存技术 |
| 能量与传递 | 热、火、燃料、光、水流、力 | 加热、冷却、燃烧、施力、导流 | 炉灶、冶炼、水力、机械和能源系统 |
| 转化与反应 | 特定条件下的物质变化、速率和副产物 | 控制温度、比例、压力、时间和催化条件 | 烹饪、发酵、冶金、化工、医药 |
| 信息与控制（后期） | 信号、储存、计算与执行 | 测量、记录、构造传感器和执行器 | 自动化、计算机、可部署的程序 |

第一条切片只让人类接触服务于生存的极小材料样本：土、木、石、植物纤维、水、食物、火与灰；并运行温度、湿度、降水、重量、支撑、渗水、燃烧、干燥和基础加工。它们是开局的样本与人类词汇，不应成为内核中唯一能存在的材料类型。

### 事实、测量、理论和技术必须分离

```text
物理事实：世界内核中的真实因果关系
测量数据：仪器或感官在特定条件下得到的有限读数
理论：某个智能体对数据的解释与可检验预测
工艺：在明确条件下可复现的操作步骤
技术：被实际制造、部署并持续运行的工艺与装置
```

语言模型写出的理论不是世界真理。它必须导出可执行的实验和可被证伪的预测；世界只负责返回测量结果。一个理论可以在社会中被相信、传播甚至被误用，但只有能稳定复现的工艺才能带来可靠的新能力。

每次实验至少记录样品、操作、地点、环境、持续时间、仪器读数和结果。实验存在测量误差、材料批次差异和失败条件，但在相同的充分条件下应当可复现；否则智能体没有可能积累真正的科学。

### 一个早期突破的例子：耐雨屋顶

智能体无需等待“瓦片科技”解锁。它可以将黏土塑形、在不同火候与时间下加热、用降雨或泼水测试渗漏、比较干燥前后的强度，再让他人复现。

若世界的因果规则确实使某个温度区间的烧制黏土变得更坚硬、低渗透，那么“烧制瓦片”会作为知识记录和工艺出现。此后它仍需要黏土、燃料、窑炉、劳力和运输；屋顶是否成功还取决于结构、施工和维护。世界没有“解锁”任何东西，人类只是学会利用原本就存在的关系。

### 对开放性的约束

开放性来自可组合的底层变量，而不是允许 Agent 任意添加新规则。智能体可以自由提出新的材料组合、结构、实验、机器和协议；但不能直接宣告“这种木头从此防水”或“我发明了永动机”。

未来的程序化机器同样遵循此原则：代码可创造新的控制逻辑，但只能通过机器实际拥有的传感、执行、能源和权限作用于世界。代码扩张的是已建成装置的行为，不是绕过物理世界的万能修改权。

### 不为每一种材料预设“上帝参数”

“黏土”“青铜”“玻璃”不应该分别拥有一套由开发者手写的属性表。任何有限的模拟都必须有一套不可变的底层物理公理，但我们只为少量**基础物质**和**结合规律**设定参数；宏观材料由它们的组合、结构和加工历史自动产生。

```text
基础物质（世界定义，数量小且稳定）
  + 结合/反应规律（世界定义）
  + 成分比例、结合拓扑、微观结构、状态与加工历史（世界演化）
  = 材料样本（可被智能体发现、命名、复制和改进）
```

因此，“黏土”只是某地沉积物中若干基础物质、水与颗粒结构形成的一个样本类别；它的名称是人类知识，而不是内核类型。智能体在热、压、混合或催化条件下得到新的稳定化合物或结构时，系统按其成分与结构生成一个新的材料实体。它可以被命名为新材料、被测量、被交易，也可以在另一个地区因杂质不同而表现不同，无须开发者添加 `newMaterial()`。

真实世界中的新材料也是如此：人类并没有发明新物理规律，而是在有限元素和规律中发现新的组合、晶体结构、合金、聚合物与器件。我们的世界应提供同样的“组合封闭、发现开放”。当然，智能体不能创造完全不受基础规律约束的第 999 种魔法元素；那相当于修改宇宙本身，而不是科学或工程。

为避免“比例的线性加权”变成无聊调参，属性不能只由成分平均得出，还必须受结合拓扑和阈值控制：同样成分在颗粒状、纤维增强、致密烧结或多孔结构下，可以有完全不同的强度、渗水和导热表现。相变、烧结、裂纹、燃烧和反应窗口提供了可被发现的非线性跃迁。

### 可实现的首版：材料状态机，而非完整分子物理

完整的现实化学、流体和结构力学既不适合浏览器实时运行，也会让智能体难以理解和实验。第一版采用“粗粒度但有深度”的材料状态模型：每一块可操作物质保存少量连续状态；世界以确定性函数计算它在环境和操作后的变化。

```ts
type MaterialSample = {
  composition: SubstanceAmount[]; // 少量基础物质的组成，不是“黏土”这类成品类型
  bonding: BondTopology; // 颗粒、纤维、致密网络、晶格等结构摘要
  mass: number;
  shape: Shape;
  temperature: number;
  moisture: number;
  compaction: number;
  porosity: number;
  firedness: number;
  damage: number;
};

type PhysicalProcess = {
  kind: "mix" | "shape" | "press" | "heat" | "dry" | "soak" | "load";
  inputs: EntityId[];
  controls: Record<string, number>; // 力度、温度目标、比例、持续时间等
  location: Position;
  duration: Duration;
};
```

这不是“黏土 + 火 = 瓦片”的配方。加热会先改变样品温度；温度、时间、含水量、压实度和成分共同改变烧结程度、孔隙和裂纹；随后世界从这些状态推导强度、脆性、渗透性和保温性。过快加热、材料比例不对或冷却不当，也会导致开裂或失败。

首版只需要少量基础物质与过程，不需要原子、分子或完整元素周期表：

```text
基础物质：黏结颗粒、砂砾、矿物骨料、植物纤维、有机燃料、水、灰
通用过程：切割、混合、塑形、压实、加热、干燥、浸泡、承重、冷却
可观察结果：重量、形状、温度、湿度、渗水、开裂、承重、燃烧
```

同一过程模型随后可加入金属、盐、矿物、电荷或生物材料，而不必改写“实验”与“创造”的系统接口。

### 物理计算的架构边界

物理引擎分成三件互不混淆的事：

```text
状态层：材料、空间、环境与结构当前是什么
过程层：某次操作在给定条件下如何改变状态
观测层：人或仪器在当前位置实际能测到什么
```

大模型绝不计算物理结果；它只提出操作、解释数据和选择下一次实验。过程层必须是确定性的、权威运行的函数，同一种样品在等价条件下应有同样结果。随机性只用于明确建模的材料批次差异、测量误差和自然事件，并且由世界种子固定，保证日志可复放。

计算也不逐原子或逐像素进行。默认以“材料样品”“建筑构件”和“地图区域”为单位更新；只有被加工、受热、受力、受雨或被测量的对象进入精细计算。远处未交互的山体、墙壁和库存保持聚合状态。这是让数百人和长期历史可运行的关键。

### 防止语言模型用已有常识跳过科学

大模型可能知道现实中的陶器、钢铁或电路。因此，世界中的材料标签不应承诺与现实完全等价，精确参数也不能出现在 Agent 的观察接口中。每张地图由稳定种子生成局部材料常数、矿物杂质、气候与工艺窗口；模型的常识只能给出假设，不能替代验证。

智能体可得到“雨后漏水率”“承受载荷”“燃烧时长”这类读数，而不是 `permeability = 0.031` 的完整内部表。它可以做对照实验、共享笔记、重复试验，或因为样品来源不同而修正旧理论。这样，科学既不退化成查攻略，也不会沦为不可解释的随机抽奖。

### 分层推进

1. **生存物理**：热、水、遮蔽、材料损耗与基础结构，让人类能通过建造改善生存。
2. **实验物理**：测量、样品、变量控制、实验记录和可复现工艺。
3. **生产物理**：更复杂的材料转化、机械传动、规模化生产与能源网络。
4. **信息物理**：通信、逻辑、计算和自动化装置；此时 AI 的 vibe coding 才成为可被部署到现实机器上的生产力。

## 科学突破，而非科技树

技术不以固定节点解锁，而以世界内的知识链存在：

```text
观察异常
  → 假设解释
  → 设计可执行实验
  → 记录测量结果
  → 他人复现或反驳
  → 形成可传播的知识/配方
  → 制造能稳定利用该知识的工具或工艺
```

“发现”本身不改变世界；只有被制造、部署、维护并投入使用的知识才扩展文明能力。这样，未来的机械化、电子计算、人工身体或脱离生物肉体，都有连续的物理和知识来路。

## 时间与规模

现有原型以 12 tick 年度经济和“每户一名代表市民”为主。具身世界需要增加个人事件时间，不应让每个人、每秒都调用一次大模型。

- 世界模拟负责高频、确定性的身体消耗、移动、生产和环境变化。
- 智能体仅在目标完成/失败、身体风险、社会互动、发现、冲突等重要节点被唤醒。
- 常规短行动由智能体已确认的计划继续执行；任何新情况都可以中断计划。
- 第一条切片只运行 20 名有姓名和完整身体状态的市民，再扩展人口规模。

这样既能保留每个人的人生与决策，也不会把文明模拟变成昂贵且不可解释的逐帧语言模型调用。

## 第一条垂直切片：冬季聚落

目标不是做完一座城市，而是证明身体压力可以自然生成协作与创造。

初始条件：20 名人类智能体、有限食物与饮水、木材和石料、一个可用水源、临近寒季、少量既有工具、可改造地形与基础居所。

必须能发生的事件：

1. 人们因冷、饿、疲劳和距离作出不同决策。
2. 人们能够采集、搬运、取水、烹饪、休息、取暖和修补遮蔽。
3. 智能体能以语言协商分工、交换物资或发生冲突。
4. 一个由人设计并实际建成的结构，可以降低局部环境风险。
5. 某人提出、验证并记录一个可复用的改进，例如更耐雨的屋顶结构或更省燃料的炉灶。
6. 每件结果都能从事件日志追溯到人的选择、材料、时间与环境条件。

验收时不看是否出现了预定的“房屋”或“市场”，而看同一套规则是否允许智能体用不同方法活过冬季，并留下可被后人继承和改进的成果。

## 暂不进入第一版的内容

- 预设职业、人格类型、道德标签或幸福评分
- 固定科技树和“研究完成”按钮
- 开局即可用的机器人、意识上传或无身体 Agent
- 任意修改全局物理规律的脚本权限
- 精确到器官、细胞或分子层面的生理模拟
- 全人口、逐秒调用大模型

这些内容要么由 System Prompt 与社会历史涌现，要么应等待具身世界和知识链稳定后再引入。

## 下一步设计决策

进入实现前，需要先确定三件事：

1. 人类身体状态的数值模型与事件阈值，确保它像生理约束而非游戏条。
2. 第一版空间表示：保留当前等距 tile 地图，还是为可改造建筑引入局部体素/结构层。
3. 智能体决策协议：System Prompt、记忆、观察、计划与世界命令的可验证数据格式。

建议先做第 1 项：它决定什么会构成每个人真实而持续的“问题”，也是后续居所、生产、协作与科技的因果起点。
