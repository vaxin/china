# 第八垂直切片：真实运行素材替换验收

**执行记录**：[execution-log.md](./execution-log.md)

## 目标与范围

把当前由 Babylon 基础几何体拼装的可见世界替换为项目内实际加载的高清手绘运行素材。建筑、住宅施工、流民、城门、道路和地表均须来自 `apps/game-web/public/assets/runtime` 下的版本化文件；基础几何体仅可作为不可见拾取、占地和调试代理存在。

本轮不改变协议 v6、施工时序、道路寻路、供水供粮、人口和存档语义。采用等距 2.5D impostor 资产嵌入 3D 世界：固定正交视角保持手绘体积感，旋转相机时选择相应朝向或保持面向相机；后续可无行为变化地升级为 GLB。

## 已采用假设

- [假设 H8-01] “真实素材”指运行时实际请求并渲染的 PNG/WebP/GLB 文件，而不是代码生成的可见方块、圆柱和纯色材质。
- [假设 H8-02] 当前最快且风险最低的落地形态为带透明通道的高清等距手绘 impostor；不可见几何代理继续负责 tile picking 与占地。
- [假设 H8-03] 已锁定的写实新国风手绘锚点、45° 等距相机、暖土/青瓦/旧木/克制朱红配色保持不变。
- [假设 H8-04] 住宅五阶段和人物动作使用单独运行文件；公共建筑、城门、道路和地表不得从整张概念图直接在 CSS/Canvas 中临时裁切。
- [假设 H8-05] 任一关键素材加载失败时保留明确的低干扰降级外观并记录错误，游戏不得白屏、丢失拾取或污染权威模拟。
- [假设 H8-06] 当前建筑只有一个美术观察方向；本轮四向 MVP 用 0°/180° 原图与 90°/270° 水平镜像交替，保证等距地面轴与网格一致。真实前后左右立面不伪造，留待后续四向资产包。

## 开发闸门与确认

用户明确要求“全换成真实素材，不要停”，且此前已授权代理自行验收和持续驱动。本轮只替换运行视觉，不改变玩法；验收判据覆盖成功、失败、边界、非法清单、迁移和跨浏览器回归。无阻塞待确认项，结论：**可以进入结构与 TDD 实现**。
