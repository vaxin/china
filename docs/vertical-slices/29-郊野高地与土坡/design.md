# 第二十九垂直切片：郊野高地与土坡结构设计

## 决策

本切片先把高差做在 **32×32 可建造城域之外**。城内继续保持 `elevation = 0` 的权威平地，现有建筑占地、道路、人物寻路、拾取和存档都不改变；郊野把连续高度采样量化为 0～4 级视觉台地，每级 2 米。同级三角形进入台地顶面，异级三角形进入独立黄土坡面材质，用真实坡带连接两个平面高度。

土坡不是一圈朝向相机的贴片：顶点仍按世界坐标真实抬高，专用位图只负责绘制裸土层理、碎石与侵蚀细节。生产画面不再绘制等高线；等高线能力从正式渲染移除。

## 空间构图

```text
远景雾面 / 现有可重定位平地
┌──────────────────────────────────────────┐
│       北侧连续高塬（远、高、轮廓完整）     │
│   ╭──────╮      ╭──────────╮             │
│ ╭─╯ 群丘 ╰──╮  ╭╯  冲沟与坡肩 ╰─╮          │
│ │            ┌────────────────┐ │          │
│ │ 西侧入城谷 │  32×32 平坦城域 │ │ 东南台塬 │
│ │  ← 城门    │ elevation = 0  │ │          │
│ │            └────────────────┘ │          │
│ ╰──低丘与缓坡──╮            ╭────╯          │
│                ╰────────────╯               │
└──────────────────────────────────────────┘
```

地貌不使用均匀随机噪声铺满四周，而采用“连续地貌块 + 次级起伏”的组织方式：

1. **城缘台地**：城界外前 2 格保持 0～0.4 米，给城墙、道路和建筑轮廓留出清楚的接地线。
2. **近郊缓坡**：城界外 2～10 格形成大量 1～5 米高的圆缓土坡，坡脚宽、坡顶不尖，局部由浅冲沟分开。
3. **远郊高塬**：10～32 格形成 6～14 米的连续高地和坡肩，重点放在北侧与东南侧，轮廓不做成一圈对称围墙。
4. **西侧入城谷**：城门 `(0,15)` 向地图外延伸一条至少 8 格宽的低谷走廊，中心线保持 0～0.6 米；两侧坡体后退，保证城门、入城道路和流民轮廓不被遮挡。
5. **西南低丘**：用较低、较密的丘群平衡正式固定镜头与平移后的画面，但不会让城市像落在陨石坑里。

## 高度合同

郊野继续使用共享世界 tile 坐标采样；渲染层增加离散级别：

```ts
type TerrainSample = {
  elevation: number;
  slope: number;
  region: "city-apron" | "gate-valley" | "rolling-hills" | "highland";
};

type TerrainTerraceSample = TerrainSample & {
  level: 0 | 1 | 2 | 3 | 4;
  visualElevation: number; // level * 2m
};

sampleSuburbanTerrain(tileX: number, tileY: number, seed: number): TerrainSample;
```

连续高度只决定台地分区，不直接作为渲染顶点高度：

```text
共享连续高度采样
→ 2m 阈值量化到 0～4 级
→ 邻接松弛，保证相邻顶点级差 ≤ 1
→ 同级三角形归入顶面，异级三角形归入坡面
```

硬约束：

- 城域内与城界顶点高度严格为 `0`，不靠视觉上“差不多平”消除接缝。
- 高度在城界外渐进，不允许第一圈顶点突升。
- 西门低谷中心不高于 0.6 米；低谷两侧 4 格内不出现高于 4 米的峰体。
- 视觉高度限制在 `0...8m`；相邻顶点最多跨一级，坡带在一个 4m tile 内连接 2m 高差，不产生竖直崖壁、针尖或跨级穿插。
- 同一 `seed` 和坐标始终返回相同结果，不读取时间、相机方向或随机全局状态。

## 渲染结构

### 固定郊野环

- 新增以城市为中心的 `96×96 tile` 固定郊野范围：城域四周各向外 32 格。
- 用两份自定义 `VertexData` 建立带 32×32 中央孔洞的环形地形：`suburban-terrace-tops` 只装同级平面，`suburban-terrace-slopes` 只装异级坡面；中央孔洞继续由现有 `city-ground` 承担拾取和建造预览。
- 两份几何共享同一套世界坐标高程合同，合计仍为 16,384 个三角形以内、2 个静态 mesh、2 个 draw call、不可拾取。
- 法线从同一个世界坐标高度函数计算，中央接缝与网格边缘使用相邻样本，避免分块亮暗裂缝。
- UV 按世界 X/Z 投影，延续现有夯土纹理尺度，不随相机平移而游动。
- 顶面继续使用现有夯土纹理；坡面使用项目内独立位图 `terrain/loess-slope-face-v2.png`，UV 的纵轴跟随 2m 高差，确保裸土层理不会像顶视纹理一样被压扁。
- 不创建正式 `LineSystem` 等高线。直坡、内外转角和斜接由同一高度格网的三角剖分自动连续，不维护手工方向图块。

### 远景地面

现有超大 `outer-terrain` 继续作为雾中的远景兜底，但只保留在固定郊野环之外。高地不能跟随 `camera.target` 重定位，否则玩家拖动相机时山体会滑动；只有无特征的最远平地可以按纹理周期重定位。

### 光照与色彩

- 城内地面和所有手绘 sprite 继续使用现有无光照材质，避免建筑人物被新灯光改色。
- 郊野 mesh 单独使用可受光的夯土材质，增加固定方向的柔和主光与环境光；不启用实时阴影。
- 坡顶偏暖黄褐、背光坡偏灰褐、坡脚略深，色差服务于高差辨识，不做高饱和绿山或雪山。
- 雾色与当前背景一致，最外圈高度和对比度逐步回落，隐藏固定网格到远景平地的交界。

## 相机、交互与兼容

- 郊野 mesh `isPickable = false`，鼠标、触屏和键盘落格仍只命中 `city-ground`。
- 当前 Q/E 保持锁定 0° 的既有行为；地形锚点只认世界坐标，不能因相机平移而重新生成或滑动。
- 城内建筑、道路、人物的 Y 值继续为现有常量，不从郊野采样高度。
- 世界快照、命令、checksum、IndexedDB schema 均不增加字段；地形种子暂时是 renderer 内版本化常量。
- 地形生成失败时降级为现有平坦郊野，游戏仍可建造和推进，不因环境表现白屏。

## 模块边界

### `packages/renderer`

- `suburban-terrain.ts`：共享高度采样适配、台地级别量化、邻接约束、顶面/坡面几何分流。
- `suburban-terrain.test.ts`：确定性、城界为零、西门低谷、0～4 级、相邻级差、网格孔洞及坡面覆盖。
- `runtime-assets.ts`：登记黄土坡面位图。
- `index.ts`：创建台地顶面与坡面两个不可拾取 mesh，绑定独立材质；保留远景平地兜底。

### `apps/game-web/e2e`

- 正式固定镜头与郊野平移截图、城门无遮挡、边界拾取、建造/拆除与平地版本一致。
- 记录地形启用前后的帧率、mesh、顶点和 draw call；不把肉眼“感觉没变慢”当作性能验收。

`protocol`、`simulation`、`persistence` 本切片不修改。

## 明确不在本切片

- 城内可建造地块的高度、坡地建筑、地基找平。
- 上坡道路、台阶、桥梁、挡土墙和人物 Y 轴行走。
- 高度影响农业、水文、风水、视野、战斗或寻路成本。
- 地形编辑器、随机地图菜单、存档地图种子。
- 河流、瀑布、矿脉、树林和可采集郊野资源。

这些能力需要权威 `elevation` 数据、v7 存档迁移、建筑基座与人物落地改造，应作为后续独立切片，而不是藏在本轮视觉地形里。
