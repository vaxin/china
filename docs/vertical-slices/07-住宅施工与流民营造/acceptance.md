# 第七垂直切片：住宅施工与流民营造验收

**执行记录**：[execution-log.md](./execution-log.md)

## 目标与范围

本轮把已确认的“新国风手绘微缩城”落实到现有住宅闭环：玩家先放置宅基地；道路接通城门后，流民从城门沿确定性最短道路走来；到达后住宅依次呈现地基、木架、封顶和成屋；成屋完成后才产生住户。施工状态、流民位置和阶段均进入权威模拟快照与存档。

本轮只替换住宅和流民的表现与入住时序。水井、农场、粮仓、市场、供水、粮食运输、工具交互和 HUD 语义保持不变；不引入建造资源、工人职业、并行施工队、寻路拥堵、税收或新建筑。

## 已采用假设

- [假设 H7-01] 新建住宅初始为 `plot`；不产生住户，也不享受住宅升级、供水或供粮。
- [假设 H7-02] 住宅相邻道路连通城门后，下一个 tick 在城门生成一名与住宅绑定的流民；每 tick 沿确定性最短道路前进一步。
- [假设 H7-03] 到达住宅边缘后依次经历 `foundation → frame → roof → complete`，每阶段至少保持一个完整 tick；完成当 tick 才产生 5 人住户和 3 tick 随身口粮。
- [假设 H7-04] 同一路网存在等长路线时按地格键（先 y 后 x）确定选择，结果不受道路数组顺序影响；多住宅按住宅 ID 处理，各自最多一名流民。
- [假设 H7-05] 流民到达前断路时不穿越空地；若当前位置失效则取消该流民并保留宅基地，恢复道路后可从城门重新出发。流民已进入施工状态后，断路不倒退施工。
- [假设 H7-06] 拆除未完工住宅同时删除对应流民；拆道路不删除住宅；补路后自动恢复迁入流程。
- [假设 H7-07] 存档升级为 v6。v1～v5 的既有住宅全部迁为 `complete`，不重播施工；新增空 `migrants`，其余 tick、revision、ID、库存和住户保持不变。
- [假设 H7-08] 首版运行资产使用 Babylon 可复用程序化 mesh 组件实现，严格按已选风格锚点制作；模型边界稳定后再无行为变化地替换为 GLB。
- [假设 H7-09] 人物使用同一套层级节点表现 `idle/walk/carry/build` 视觉动作；移动由模拟格坐标与渲染插值控制，不使用 root motion。

## 开发闸门与确认

用户已明确确认风格并要求开始落地实现，同时在第一切片后授权代理自行验收和持续驱动。本轮严格限定为此前已确认的“宅基地 → 流民 → 施工 → 成屋入住”MVP，不扩展玩法；成功、失败、边界、非法状态、迁移、恢复、视觉和全量回归均有可观察判据。无阻塞待确认项。结论：**验收基线确认，可以进入 TDD**。
