# L 型道路母版

运行时道路的 L 型图块只维护一个母版：`06-es-master.png`。

- `06-es.png`：母版，连接东、南。
- `0c-sw.png`：母版顺时针旋转 90°，连接南、西。
- `09-nw.png`：母版旋转 180°，连接北、西。
- `03-ne.png`：母版顺时针旋转 270°，连接北、东。

母版来自已验收的 Image Gen L 型图：`06-es-source.png`（原始生成文件名为
`exec-52f3c687-d652-4a15-b638-b3a7263d9e38.png`）。它等比缩放到 512×512 后，
套用 L 型透明轮廓，确保非道路区域露出地图本身的草地。

最终运行时图片均从 `06-es-master.png` 旋转得到；不要再从 T 型图裁切或分别重绘四张。
