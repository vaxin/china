# style_anchor_city_v01 风格锁定

- 视觉方向：新国风手绘微缩城（stylized hand-painted miniature realism）
- 世界气质：虚构河洛平原，晚唐至北宋民居气息，原创而不复刻既有游戏资产
- 相机：固定 45° 正交/等距三分之四视角
- 光线：柔和午前日光，彩色软阴影，轻微空气透视
- 主色：黄土赭、暖灰墙、青灰瓦、深木褐、灰绿、稻金
- 强调色：克制朱红，只用于布棚、门饰和小面积视觉提示
- 人物：5～5.5 头身，非 Q 版，手和工具适度放大保证中远景可读
- 材质：可信几何 + 手绘矿物色 + 柔和 PBR 粗糙度 + 轻 AO；避免塑料玩具感
- 明确避免：旧式精灵图观感、泥黄滤镜、写实照片感、通用低模方块、宫廷满屏红金、水彩糊染和奇幻元素
